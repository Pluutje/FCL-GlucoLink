The Dexcom G7/ONE+ home screen card now shows "Last connected" and how long the sensor has been running, matching the other sensor types — it previously only showed "Connected" with nothing else. That running time now also correctly restarts from zero whenever you pair a new physical G7 sensor, instead of carrying over from the previous one.

Cleaned up the G7 sensor screen: removed a number of technical fields that never actually get filled in for this sensor (they were always blank, and always will be — not a temporary gap), along with a couple of version-number fields that were filled in but too technical to be useful. The "Running" line on the Diagnostics section now also works for G7. The sensor status line shows a short technical reference code alongside its plain-language description, in case that's ever useful when discussing a sensor problem.
