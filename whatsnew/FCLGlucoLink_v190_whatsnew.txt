Added a safety net for crashes in the CareSens Air native calibration code. Until now, if this specific part of the app crashed, it disappeared without leaving any trace in the log — even the app's own crash logging couldn't see it. Such a crash now gets recorded (signal + technical location) in the same daily log file used by "Send log files" in Settings, so a crash can be diagnosed from that log alone, without needing a technical bug report from the phone itself.
