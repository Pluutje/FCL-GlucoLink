Dexcom G6: een nieuwe sensor starten lukt nu ook als er nog een oude sessie in de zender loopt. De stop-opdracht gebruikte een verkeerde stoptijd, waardoor de zender "ok" zei maar de oude sessie bleef lopen en de nieuwe nooit startte. Nu wordt de huidige zendertijd meegestuurd. Na 3 stops zonder effect probeert de app de start alsnog, zodat je een duidelijke melding krijgt in plaats van een eindeloze lus.
---EN---
Dexcom G6: starting a new sensor now also works when the transmitter still has an old session running. The stop command used a wrong stop time, so the transmitter said "ok" but kept the old session and the new one never started. The app now sends the current transmitter time. After 3 stops without effect the app tries the start anyway, so you get a clear message instead of an endless loop.
