Added deeper diagnostics for the CareSens Air frozen-data problem. Until now, the app's own decisions about incoming sensor data (accepted, ignored, or an error) only went to a technical system log that a non-technical tester cannot retrieve — the "Send log files" button did not include them. They are now written to that same daily log file, so a future freeze can actually be diagnosed from a tester's own log.

Also widened the automatic recovery added in the last two updates: it previously could only kick in after at least one real reading had been accepted for a given sensor session. A session that never accepts a single reading from the very start could not be helped at all. It now also starts its recovery clock from the first data received, even if no reading has been accepted yet.
