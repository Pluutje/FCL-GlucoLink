Fixed a Dexcom G7/ONE+ bug where updating the app could break the connection to a sensor that was already running, requiring you to forget and re-pair it. The app was only remembering its "fast reconnect" security key in memory, so any app restart (including an update) forced the very next reconnect to take a much slower path — and the G7 only allows a short window to hand over a reading before it starts treating the connection as unreliable. That key is now saved properly, so a future app update shouldn't cause this anymore.
